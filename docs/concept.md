# Concept

**Status:** draft. Decisions are recorded here as they are made.

## 1. Architecture

Open question: which responsibilities belong to the indoor unit,
the outdoor sensor and the server.

## 2. Outdoor sensor connectivity

Candidates: Wi-Fi, ESP-NOW, LoRa, 868 MHz module.
Main criterion: energy per transmission on battery power.

## 3. Sensors and display

To be selected: temperature/humidity/pressure sensors, e-paper panel.

## 4. Measurable differentiator

Candidates:
- battery life, calculated and verified by measurement
- documented measurement error (radiation shield, two-sensor comparison)
- local forecast accuracy compared with Zambretti or a weather API
